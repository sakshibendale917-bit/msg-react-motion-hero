# MSG React Motion Hero — Complete Version

A responsive animated hero landing page made with React, Vite, Tailwind CSS, Framer Motion, and Lucide React.

## Included requirements

- React + Vite project structure
- Tailwind CSS 3 configured with PostCSS and Autoprefixer
- Cursor-following glow orb using `useMotionValue` and `useSpring`
- Scroll parallax using `useScroll` and `useTransform`
- Three floating concept cards
- Framer Motion headline, entrance, and hover animations
- Reduced-motion support using `useReducedMotion` and `prefers-reduced-motion`
- All editable page copy and card content stored in `src/data/motionHeroData.js`
- Responsive layout rules for desktop, tablet, and mobile
- Production build script

## Requirements

- Node.js 18 or newer
- VS Code (recommended)
- Internet connection for Google Fonts and npm package installation

## Run in VS Code (Windows)

1. Extract the ZIP file.
2. Open the extracted `msg-react-motion-hero-complete` folder in VS Code.
3. Select **Terminal → New Terminal**.
4. If PowerShell blocks `npm.ps1`, use `npm.cmd` commands below.

Install dependencies:

```powershell
npm.cmd install
```

Start the development server:

```powershell
npm.cmd run dev
```

Open the localhost URL printed in the terminal (normally `http://localhost:5173`).

## Test production build

```powershell
npm.cmd run build
```

Vite creates the production site in the `dist` folder. Preview that build with:

```powershell
npm.cmd run preview
```

## Customize the content

Edit `src/data/motionHeroData.js` to change:
- Brand name
- Navigation labels and links
- Eyebrow, headline, and description
- CTA labels and destinations
- The three cards
- Statistics and footer text

## Responsive testing checklist

Test the page in browser DevTools at approximately:
- Mobile: 375px
- Tablet: 768px
- Desktop: 1440px

Check that there is no horizontal scrolling, all three cards remain visible, and buttons/anchor links work.

## Deployment (Netlify)

- Build command: `npm run build`
- Publish directory: `dist`
- Node version: 18 or newer

Do not upload `node_modules`. Commit the source files and lockfile (if generated by `npm install`) to GitHub.

## Important

The mobile menu icon is currently a visual menu affordance; desktop navigation links and CTA anchor links work. The project is supplied as source code. Run the build and visually test it in your own browser before submitting it for review.
